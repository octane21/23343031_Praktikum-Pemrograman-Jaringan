## Jobsheet 1 – Pengantar Node.js
Jobsheet ini membahas pemanfaatan Node.js sebagai runtime JavaScript di sisi server untuk membangun aplikasi jaringan yang efisien, responsif, dan skalabel. Pembahasan dimulai dari konsep dasar seperti arsitektur client–server, protokol jaringan, socket, serta perbedaan pendekatan sinkron dan asinkron dalam komunikasi jaringan, kemudian  karakteristik Node.js yang mengadopsi model non-blocking dan event-driven melalui mekanisme event loop. Node.js memiliki peran penting dalam pengembangan aplikasi web dan layanan jaringan modern karena mampu menangani banyak koneksi secara bersamaan dengan penggunaan sumber daya yang optimal, didukung oleh modul bawaan seperti HTTP/HTTPS serta ekosistem NPM yang kaya.

## Jobsheet 2 – Node.js Module System
Jobsheet ini membahas sistem modul pada Node.js sebagai mekanisme untuk mengorganisasi kode JavaScript menjadi bagian-bagian kecil yang modular, terstruktur, dan dapat digunakan kembali. Konsep dasar sistem modul berbasis CommonJS, termasuk penggunaan fungsi require() untuk mengimpor modul dan module.exports untuk mengekspor fungsi atau data antar file, serta pemanfaatan modul bawaan seperti fs dan http. Peran NPM sebagai pengelola paket dalam ekosistem Node.js yang memungkinkan instalasi, pengelolaan dependensi, dan penggunaan pustaka pihak ketiga melalui file package.json.

## Jobsheet 3 – HTTP Request dan API
Jobsheet ini membahas mekanisme komunikasi data antara klien dan server melalui HTTP request serta pemanfaatan API sebagai jembatan integrasi antar sistem dalam pengembangan aplikasi berbasis Node.js. Sebuah aplikasi mengirim permintaan (request) ke server atau layanan eksternal menggunakan metode HTTP tertentu dan menerima respons dalam format terstruktur seperti JSON untuk kemudian diolah sesuai kebutuhan aplikasi. Konsep API sebagai antarmuka abstrak yang memungkinkan pengembang mengakses layanan pihak ketiga tanpa harus mengetahui detail implementasi internalnya, sehingga mempercepat pengembangan dan mendorong modularitas sistem. Pemanfaatan HTTP request digunakan untuk mengambil data nyata dari layanan eksternal, seperti informasi cuaca dan lokasi, yang menunjukkan bagaimana Node.js berperan sebagai penghubung logika aplikasi dengan sumber data eksternal secara dinamis, fleksibel, dan efisien dalam membangun aplikasi jaringan modern

## Jobsheet 4 – JavaScript Essentials
Jobsheet ini membahas peran fundamental JavaScript sebagai bahasa pemrograman utama dalam pengembangan aplikasi berbasis jaringan, terutama dalam membangun interaksi antara pengguna dan sistem melalui web. JavaScript sebagai bahasa yang memungkinkan halaman dan aplikasi jaringan menjadi dinamis, responsif, serta mampu menangani interaksi pengguna secara langsung tanpa harus memuat ulang sistem secara keseluruhan. JavaScript berfungsi sebagai penghubung antara antarmuka pengguna dan server, baik untuk mengirim maupun menerima data secara asinkron, sehingga pengalaman pengguna menjadi lebih cepat dan efisien.

## Jobsheet 6 – JSON HTTP Endpoints
Jobsheet ini membahas konsep dan implementasi JSON HTTP Endpoints dalam pengembangan aplikasi berbasis jaringan menggunakan Node.js dan Express.js. JSON HTTP Endpoints berfungsi sebagai titik akhir (URL) yang memungkinkan pertukaran data antara klien dan server dalam format JSON melalui protokol HTTP, sehingga komunikasi data menjadi ringan, terstruktur, dan mudah diproses. Jobsheet ini menjelaskan penggunaan query string (req.query) untuk menerima input dari pengguna, pembuatan endpoint yang bersifat dinamis, serta integrasi layanan API eksternal seperti geocoding dan cuaca untuk menghasilkan data yang relevan.

## Jobsheet 8 – MongoDB dan Database Server
Jobsheet ini membahas konsep database server serta penggunaan MongoDB sebagai basis data NoSQL dalam pengembangan aplikasi berbasis jaringan menggunakan Node.js. Peran database server sebagai pusat penyimpanan dan pengelolaan data yang mendukung akses terstruktur, aman, dan efisien oleh berbagai aplikasi. ## Jobsheet 9 – Socket Programming
Jobsheet ini membahas konsep Socket Programming sebagai pendekatan untuk membangun komunikasi real-time dalam aplikasi berbasis jaringan menggunakan WebSocket dan Socket.IO pada platform Node.js. Socket programming sebagai mekanisme komunikasi dua arah antara klien dan server melalui soket, yang memungkinkan pertukaran data secara langsung tanpa harus menunggu permintaan berulang seperti pada HTTP tradisional. Perbedaan WebSocket dan HTTP, keunggulan WebSocket dalam hal latensi rendah dan koneksi yang persisten, serta peran Socket.IO sebagai library yang menyederhanakan implementasi komunikasi real-time berbasis event.
